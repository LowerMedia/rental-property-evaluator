# Release notes — v1.4.0

**Released:** 2026-06-09
**Tag:** `v1.4.0`
**Quality gate:** lint, typecheck, tests, build all green — 799 tests across 43 files (up from 651 / 26 at v1.3.0)

v1.4.0 completes the E7 import epic end to end — paste an address, a Zillow/Redfin/Realtor/Trulia/Homes.com URL, or the listing's copied text, and the deal fills itself in through a tiered, provenance-tagged resolver with a review panel that never silently overwrites your edits. Plus three quality-of-life features: a golden Example deal, a light/dark theme, and an explainable score.

## E7 (completed) — Address / listing-URL autofill — RPE-43 (RPE-44–54)

- **`@rpe/property`** (new package) — `PropertyLookup` provenance types (per-field value/source/confidence), `PropertyProvider` interface, and `resolveProperty()`: providers run sequentially in `api → scrape → paste` tier order, fields merge first-tier-wins, the chain stops at the first acceptable result, failures are recorded in a per-attempt audit trail (RPE-44).
- **Proxy guardrails** — `/property` gained a provenance-tagged `lookup` envelope, typed error codes, key-scoped address caching, and per-IP rpm + daily-cap rate limits; cache hits are quota-free (RPE-45).
- **`GET /geocode`** — address normalization via the keyless US Census geocoder behind a provider-agnostic candidate shape; ambiguous input returns a disambiguation list, never a guess (RPE-46).
- **Listing-URL parser** — pure string parsing for the five supported hosts; lookalike hosts rejected; everything else falls back to freeform address (RPE-47).
- **RentCast primary provider** — full property record (beds/baths/sqft/year built/units/taxes) + AVM value/rent, mapped with per-field confidence; swappable interface for ATTOM/Estated later (RPE-48).
- **Comps & history** — `POST /property/context`: rent/sale comps, tax history, price history; read-only context sharing one provider-call budget with `/property` (RPE-49).
- **Lookup → DealInputs mapping** — patch-based with `needsReview` flags; `applyLookupPatches()` never writes a user-edited target (RPE-50).
- **Scrape fallback** — OFF by default (`RPE_SCRAPE_ENABLED`); SSRF-contained (https-only, host allowlist, post-redirect re-validation); results forced to `scrape`/`low` "unverified source"; enabling in production remains a product/legal call (RPE-51).
- **Paste-text parser** — labeled-number heuristics, zero keys/cost/ToS exposure; the import works before RentCast is even configured (RPE-52).
- **Import UI** — paste/import bar + review/override panel with source badges, confidence chips, and accept checkboxes; low-confidence rows and rows over user-edited values demand explicit confirmation (RPE-53). Verified end-to-end in a live browser walkthrough.
- **E2E test chains** — URL → resolver → patches → reducer → engine; api → paste fall-through; scrape-flag cost-ordering; review-panel selection-defaults regression (RPE-54).

## Standalone features

- **Golden Example deal (RPE-68)** — `EXAMPLE_DEAL_INPUTS`/`_EXPECTED` in `@rpe/engine`, hand-verified and `toBe`-locked in CI; ★ "Load Example" in the scenario tabs.
- **Light/dark theme (RPE-69)** — runtime toggle, pre-paint bootstrap (no flash), OS-preference default, persisted choice, print always light, AA contrast verified.
- **Score explanation (RPE-70)** — "How is this scored?" disclosure rendering all scored metrics from `SCREENER_METRIC_CONFIG` with live pass/fail; accessible; excluded from print.

## Process notes

- Copilot remained unavailable; every story shipped via the strict self-review loop. Notable catches: a redirect-SSRF residual in the scrape route, a rate-limiter memory bound under spoofed-XFF floods, defaults-vs-edits selection in the review panel (caught in a live preview walkthrough), and an IEEE-754 fixture-locking mismatch.
- RPE-71 was triaged as **misfiled** (Laravel/Fortify bug referencing `reid.lndo.site` — belongs to the REID project) and excluded from this release.
