# v1.12.0 — verdict chip, key-metrics strip, cap-rate all-in toggle, Simple-default + persisted mode

**Released:** 2026-06-21
**Stories:** [RPE-108](https://lowermedia.atlassian.net/browse/RPE-108), [RPE-109](https://lowermedia.atlassian.net/browse/RPE-109), [RPE-105](https://lowermedia.atlassian.net/browse/RPE-105), [RPE-110](https://lowermedia.atlassian.net/browse/RPE-110)
**Gate:** 991 tests / 70 files (1 env-gated Postgres skip), lint + typecheck + build green.

## Highlights

A scoring + onboarding release: a clearer at-a-glance verdict, the decision-driving
metrics surfaced, an optional all-in cap-rate basis, and a faster first run that
defaults to Simple with the chosen mode remembered.

## RPE-108 — go/no-go verdict chip

A **Pass / Marginal / Fail** chip beside the Score (≥75% / ≥50% / below) so a
buy/pass call doesn't require reading every row. The band thresholds and the
score calc are now a single source of truth in `@rpe/engine` (`scoreVerdict` +
`evalSignal` + `computeScreenerScore`) — the ScoreCard, the mobile sticky bar,
the Pro-Forma header, and the Comparison view all derive from it, and the verdict
is included in the CSV and PDF export headers. Engine tests assert the 49/50/74/75%
band boundaries.

## RPE-109 — key metrics strip

A "Key Metrics" strip pins the four decision-drivers (Cash Flow, DSCR,
Cash-on-Cash, Cap Rate) above the full grouped list, reusing the existing
pass/fail signals. (Lightweight surfacing; the weighted-score option was deferred
in grooming.)

## RPE-105 — cap rate all-in basis toggle

An optional toggle computes cap rate on the all-in cost (purchase price + rehab +
out-of-pocket closing) instead of price alone — a truer yield for BRRRR /
heavy-rehab deals. Defaults to the price basis (existing results unchanged); the
basis is surfaced in the metric tooltip.

## RPE-110 — first-run Simple + persisted mode

First load now defaults to **Simple** mode (the fast triage path); the last-used
mode (Simple/Complex, Screener/Pro-Forma) is persisted to localStorage and
restored on return. Share links encode the view mode, so a shared scenario opens
in the sharer's mode, overriding the persisted default. Account-scoped
cross-device sync is a follow-up — localStorage covers the per-browser case for
both anonymous and signed-in users.
