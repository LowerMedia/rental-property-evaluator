## RPE-98 — deploy infrastructure

- `.do/` app specs (prod / stage / dev): static `web` + Dockerized `api` +
  Postgres per app; ingress routes `/v1` **and** the legacy unprefixed SPA
  paths to the api with `preserve_path_prefix` (App Platform strips
  matched prefixes by default) — same-origin cookie auth with zero code
  changes.
- `apps/api/Dockerfile`: pnpm monorepo build, pruned runtime
  (`pnpm deploy --legacy --prod`), drizzle migrations shipped at
  `/app/migrations`, `package.json` for boot version reporting.
- `@rpe/db` hardening for DO Postgres: tiered TLS (`pgSsl` — PEM-sniffed
  `DATABASE_CA_CERT` verification, explicit `DATABASE_SSL_NO_VERIFY` for
  dev-tier DBs), `stripUrlSslParams` (node-postgres discards config-object
  ssl when the URL carries `sslmode`), and an owned pg migration runner
  (`migratePgWithoutSchemaCreate` — DO db users lack CREATE on the
  database; postgres checks the privilege before IF-NOT-EXISTS; journal
  lives in `public.__drizzle_migrations`).
- Buildpack fixes: `engines` capped `>=20 <25` (Node 26 dropped corepack;
  the DO buildpack needs it for pnpm), CI pnpm version conflict resolved
  (develop CI had been red at setup since 2026-06-10).
- `apps/web/.env.production`: origin corrected to
  `rentalpropertyevaluator.com`, same-origin `VITE_API_URL`, auth shell
  enabled, real AdSense client committed (ads still gated off).
- `docs/deploy.md` runbook: provisioning, secrets matrix (encrypted EV
  round-trip), Cloudflare/DNS, cutover with rollback, smoke checklists.
- Operational learning baked into specs/runbook: legacy (2021-era) DO
  apps are generation-pinned to the old build system with no upgrade
  path — stage was recreated from spec (new app id); dev was updated in
  place.
